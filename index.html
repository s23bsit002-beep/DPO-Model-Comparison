Direct Preference Optimization Experiment

Base Model vs DPO Beta 0.1 vs DPO Beta 0.2

Project Overview

This project explores Direct Preference Optimization (DPO) using the Qwen2.5-0.5B language model. Two experiments were conducted using different beta values: 0.1 and 0.2.

Models Used

Base Model

Qwen2.5-0.5B

Original model before DPO training.

DPO Beta 0.1

Beta value: 0.1

Trained using preference data.

DPO Beta 0.2

Beta value: 0.2

Trained using preference data.

Training Details

Dataset: trl-lib/ultrafeedback_binarized

Base Model: Qwen/Qwen2.5-0.5B

Training examples: 500 for each experiment

Training steps: 50

Training Loss Comparison

Model Training Loss
DPO Beta 0.1 0.682726
DPO Beta 0.2 0.679262

Manual Evaluation Results

Model Average Score
Base Model 3.25
DPO Beta 0.1 3.25
DPO Beta 0.2 4.00

DPO Beta 0.2 achieved the highest average score in this manual evaluation.

Conclusion

The experiment shows how DPO can be used to train language models using preferred and rejected responses. Among the tested models, DPO Beta 0.2 received the highest manual evaluation score. Further testing is required to confirm this result.
